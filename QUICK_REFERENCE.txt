🔍 SCAN TYPES
═══════════════════════════════════════════════════════════════════════
   Exact Value              - Find specific value (e.g., 1000)
   Unknown Initial Value    - Find all non-zero values
   Increased Value          - Value went up
   Decreased Value          - Value went down
   Changed Value            - Any change occurred
   Unchanged Value          - Value stayed same
   Bigger Than              - Value > X
   Smaller Than             - Value < X
   Value Between            - Min <= Value <= Max
   Increased By             - Value increased by exact amount
   Decreased By             - Value decreased by exact amount

💾 DATA TYPES
═══════════════════════════════════════════════════════════════════════
   int32       - 4-byte integer (-2B to 2B)
   int64       - 8-byte integer (large numbers)
   float       - 4-byte floating point
   double      - 8-byte floating point
   string      - Text/ASCII strings
   byte_array  - Raw byte sequences
   pattern     - AOB patterns with wildcards (48 8B ?? 90)

📤 EXPORT OPTIONS
═══════════════════════════════════════════════════════════════════════
   Full Memory Dump    - Complete process memory (.dmp)
   Selected Region     - Export specific address range
   Scan Results        - Export to JSON with metadata
   Memory Snapshot     - Capture current state
   Snapshot Comparison - Diff two snapshots

🛠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════
   "Failed to create StealthEngine"
   → Run as Administrator
   → Check StealthEngine\StealthEngine.dll exists

   "Failed to attach to process"
   → Ensure process is running
   → Try different process (e.g., Notepad for testing)
   → Run with admin privileges

   "No results found"
   → Try different data type (int64 instead of int32)
   → Increase scan range
   → Use "Unknown Initial Value" then narrow down

   "Slow scanning"
   → Reduce scan range size
   → Close other applications
   → Use SSD instead of HDD
